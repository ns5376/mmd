Catalog Extraction Console

Upload a PDF, open the job, then choose the exact pages to process.

The app converts the PDF into reusable page images, keeps a job record for each upload, and runs the extraction pipeline plus WAAMD matching on the range you pick. Each user supplies their own Anthropic API key when they start a run.

How It Works

  1. Upload a PDF on the home page.
  2. Open the generated job from the uploads list.
  3. Choose the page range and run the pipeline.
